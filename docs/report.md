## 1. Введение и цели проекта
Проект представляет собой сайт школы танцев «Ритм Холл», созданный для набора групп к новогоднему концерту. Основная цель — сбор заявок на пробные занятия и отслеживание эффективности рекламных каналов с помощью сквозной аналитики.

## 2. Создание и публикация сайта
Сайт состоит из 11 страниц (включая 404.html) и сверстан на чистом HTML, CSS и JavaScript. Сайт опубликован на платформе Vercel и доступен по ссылке выше. Код проекта хранится в репозитории GitHub.

## 3. Настройка веб-аналитики (Google Analytics 4)
В GA4 был создан ресурс «РИТМ ХОЛЛ — сайт» и поток данных для сайта на Vercel. Тег `gtag.js` установлен на всех страницах сайта.
Были настроены следующие события:
- `page_view` (автоматическое).
- `cta_click` (клики по кнопкам записи).
- `form_start` (начало заполнения формы).
- `social_click` (клики по ссылкам соцсетей).
- **`generate_lead`** (успешная отправка формы). Это событие отмечено как Key event (Ключевое событие).

**Скриншот события generate_lead в GA4 (Realtime):**

## 4. Сбор заявок (Apps Script + Google Sheets)
Для приема заявок была создана Google Таблица «RitmHall — Leads». Скрипт Google Apps Script принимает POST-запросы от формы, проверяет данные (обязательные поля, формат телефона и email) и записывает строку в таблицу. Статус заявки по умолчанию — `new`.

## 5. UTM-разметка
Для отслеживания источников трафика была настроена передача UTM-меток из адресной строки в скрытые поля формы. При тестировании ссылки с параметрами `utm_source=telegram&utm_medium=social&utm_campaign=newyear_show_2026` данные успешно записались в соответствующие столбцы Google Таблицы.

## 6. Автоответы в Instagram (ManyChat)
В ходе выполнения работы была предпринята попытка настройки автоответов через сервис ManyChat (раздел 7 ТЗ). Была создана Страница Facebook «Ритм Холл». Однако сервис ManyChat с 1 августа 2024 года официально блокирует доступ для пользователей из России (код ошибки 451). В связи с этим настройка автоответов оказалась технически невозможной.

## 7. Вывод
В результате работы был создан полностью функциональный сайт с настроенной системой веб-аналитики. Реализован сбор заявок в Google Таблицу с сохранением UTM-меток, что позволяет отслеживать эффективность рекламных каналов и конверсию в заявки. Ограничения со стороны ManyChat не позволили завершить настройку автоответов, однако это не повлияло на основную функциональность проекта.
