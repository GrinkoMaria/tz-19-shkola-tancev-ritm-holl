# Аналитическая записка по проекту «Ритм Холл»

**Ссылка на сайт:** https://tz-19-shkola-tancev-ritm-holl-liart.vercel.app/
**Ресурс GA4:** G-K0RDRQXZ9W

## 1. Настройка аналитики
В ходе работы был создан ресурс Google Analytics 4. Тег gtag.js установлен на всех 11 страницах сайта. Включена расширенная статистика (Enhanced measurement) для отслеживания скроллов и кликов.

## 2. Ключевые события
Настроены следующие события (согласно ТЗ):
- `cta_click` (клики по кнопкам записи).
- `form_start` (начало заполнения формы).
- `social_click` (клики по ссылкам соцсетей в подвале).
- **`generate_lead`** (успешная отправка формы). Это событие отмечено как Key event (Ключевое событие).

## 3. Сбор заявок
Настроена сквозная интеграция: форма на сайте -> Google Apps Script -> Google Таблица «RitmHall — Leads».
В таблицу передаются: имя, телефон, email, направление, уровень, удобное время и UTM-метки. Настроены выпадающие списки (Data Validation) и условное форматирование для контроля качества данных.

## 4. Тестирование UTM-меток
Проверена передача UTM-меток. При переходе по ссылке с параметрами `utm_source=telegram&utm_medium=social&utm_campaign=newyear_show_2026`, данные успешно записались в соответствующие столбцы таблицы (заявка "Тест UTM").

## 5. CRM HubSpot
В рамках раздела 9 ТЗ была настроена бесплатная CRM HubSpot. 
1. Создана воронка сделок «Ритм Холл · Ученики».
2. Импортированы данные из Google Таблицы через расширенный импорт. Успешно создан контакт (заявка от Ивана).

## 6. Автоответы (ManyChat) и обоснование выбора платформы
В рамках раздела 7 ТЗ требовалось настроить автоответы в Instagram через ManyChat. 

**Важное примечание:** В ходе выполнения работы исполнитель столкнулся с объективными техническими ограничениями со стороны Meta. На этапе авторизации и попытки привязки аккаунта Instagram к Facebook (требуемого для работы ManyChat) возникала критическая ошибка соединения (`ERR_CONNECTION_ABORTED`), вызванная блокировкой доступа к сервисам Meta из РФ. 

**Решение:** Для успешного выполнения практической части ТЗ, связанной с настройкой сценариев ManyChat, было принято решение использовать альтернативный, стабильно работающий канал — **Telegram**.
В ManyChat создан сценарий: при команде `/start` пользователь получает приветственное сообщение и кнопку «Записаться», ведущую на сайт.

## 7. Вывод
Несмотря на ограничения доступа к некоторым зарубежным сервисам, основная цель проекта достигнута. Созданный сайт и настроенная система аналитики позволяют в реальном времени отслеживать эффективность рекламных каналов. Благодаря передаче UTM-меток и события `generate_lead`, можно точно определить, из какого источника пришел клиент, а использование альтернативного Telegram-бота позволило выполнить задачу автоматизации взаимодействия с клиентами.
