## 📋 Что реализовано в проекте

### 1. Сайт (11 страниц)
- Верстка на чистом HTML, CSS и JavaScript (без использования сборщиков и фреймворков).
- Адаптивный дизайн (корректно отображается на ПК, планшетах и смартфонах).
- Фирменный стиль: малиновый `#E0306F`, черный `#141217`, светлый `#F7F4F6`, акцентный желтый `#FFC93C`.
- Шрифты: Bebas Neue (заголовки) и Inter (текст).
- Публикация на платформе Vercel с автоматическим деплоем при пуше в ветку `main`.

### 2. Веб-аналитика (Google Analytics 4)
- Установлен тег `gtag.js` на всех страницах (включая 404).
- Настроены события: `page_view`, `scroll`, `cta_click`, `form_start`, `social_click`.
- **Ключевое событие:** `generate_lead` (отправляется при успешной отправке формы).
- Передача пользовательских параметров (например, `lead_style`, `lead_level`).

### 3. Прием заявок (Apps Script + Google Sheets)
- Настроена интеграция формы с Google Таблицей через Google Apps Script (`apps-script/Code.gs`).
- Реализована валидация данных на стороне сервера (проверка телефона, email, обязательных полей).
- Защита от дублей (проверка `request_id`).
- Передача UTM-меток из адресной строки в таблицу для отслеживания источников трафика.
